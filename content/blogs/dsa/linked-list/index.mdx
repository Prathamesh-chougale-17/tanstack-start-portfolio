## Why Linked Lists Matter

Linked list interviews are less about memorizing pointer tricks and more about staying disciplined with:

- pointer movement
- dummy nodes
- edge cases near the head
- splitting and reconnecting pieces safely

If arrays test indexing, linked lists test pointer reasoning.
